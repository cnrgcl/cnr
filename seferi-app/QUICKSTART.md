# ⚡ Hızlı Başlangıç - 5 Dakikada Çalıştır!

## 🚀 Adım 1: Firebase Kurulumu (3 dakika)

1. [Firebase Console](https://console.firebase.google.com/) → Yeni proje oluştur
2. Authentication → Email/Password aktif et
3. Firestore Database → Test modunda oluştur
4. Storage → Test modunda oluştur
5. Project Settings → Web app ekle → Config bilgilerini kopyala

**Detaylı rehber**: [FIREBASE_SETUP_GUIDE.md](./FIREBASE_SETUP_GUIDE.md)

## 💻 Adım 2: Kod Kurulumu (1 dakika)

```bash
# Bağımlılıkları yükle
npm install

# Firebase config'i güncelle
# src/services/firebase.ts dosyasına config bilgilerini yapıştır
```

## ▶️ Adım 3: Çalıştır (1 dakika)

```bash
# Başlat
npm start

# QR kodu Expo Go ile tara
# veya 'w' tuşuna basarak web'de aç
```
