# 🚀 Kodlama Dersleri - Python ile Programlamaya Başlangıç

Merhaba! Bu klasörde Python programlama dilini öğrenmek için hazırlanmış basit dersler bulunuyor.

## 📚 Dersler

### Ders 1: İlk Programınız (1_merhaba.py)
- Ekrana yazı yazdırma (`print`)
- Değişkenler kullanma
- Basit matematik işlemleri

**Çalıştırmak için:**
```bash
python3 1_merhaba.py
```

### Ders 2: Koşullar (2_kosullar.py)
- `if`, `elif`, `else` yapıları
- Programın karar vermesi
- Karşılaştırma işlemleri

**Çalıştırmak için:**
```bash
python3 2_kosullar.py
```

### Ders 3: Döngüler (3_donguler.py)
- `for` döngüsü
- `while` döngüsü
- Listeler ile çalışma
- Tekrarlayan işlemler

**Çalıştırmak için:**
```bash
python3 3_donguler.py
```

### Ders 4: İnteraktif Program (4_interaktif.py)
- Kullanıcıdan veri alma (`input`)
- Veri tipi dönüşümleri
- Kişiselleştirilmiş mesajlar

**Çalıştırmak için:**
```bash
python3 4_interaktif.py
```

### Ders 5: Sayı Tahmin Oyunu (5_tahmin_oyunu.py)
- İlk gerçek projeniz!
- Rastgele sayı üretme
- Döngü ve koşulları birlikte kullanma
- Oyun mantığı

**Çalıştırmak için:**
```bash
python3 5_tahmin_oyunu.py
```

### Ders 6: Hesap Makinesi (6_hesap_makinesi.py)
- Dört işlem yapan program
- Kullanıcı seçimleri
- Hata kontrolü

**Çalıştırmak için:**
```bash
python3 6_hesap_makinesi.py
```

## 🎯 Öğrenme Yolu

1. **İlk olarak** dosyaları sırayla oku ve kodu anlamaya çalış
2. **Sonra** her programı çalıştır ve çıktıları incele
3. **Dene ve değiştir**: Kodları kendin değiştirip ne olacağını gör
4. **Kendi programını yaz**: Öğrendiklerini birleştirerek yeni şeyler yap

## 💡 İpuçları

- Her satırı okuyup anlamaya çalış
- Yorumları (# ile başlayan satırlar) dikkatlice oku
- Hata almaktan korkma - hatalar öğrenmenin bir parçası!
- Kodu değiştirip dene, ne olacağını gör
- Kendi fikirlerini kodlamaya çalış

## 🚀 Sonraki Adımlar

Bu dersleri bitirdikten sonra şunları deneyebilirsin:

1. Kendi oyununu yaz (taş-kağıt-makas gibi)
2. Basit bir yapılacaklar listesi programı yap
3. Kelime oyunu yaz (adam asmaca gibi)
4. Basit bir not defteri programı oluştur
